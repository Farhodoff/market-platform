# 🚀 React + Django 30 kunlik o‘rganish rejasi (Notion format)

## 🎯 Maqsad
30 kun ichida React (frontend) va Django (backend) texnologiyalarini asosiy darajada o‘zlashtirish hamda bitta to‘liq full-stack loyiha tayyorlash.

---

## 📅 O‘rganish Rejasi

### 1–10-kun: Asoslar

**React:**
- [ ] JSX va komponentlar
- [ ] Props, State (`useState`)
- [ ] `useEffect` bilan ishlash
- [ ] Mini loyihalar: Counter, To-do

**Django:**
- [ ] MVT tuzilmasi
- [ ] Model, View, Template yaratish
- [ ] Admin panel sozlash
- [ ] CRUD (create/read/update/delete)

---

### 11–20-kun: API va Integratsiya

**React:**
- [ ] React Router
- [ ] Form handling
- [ ] API chaqirish (fetch, axios)
- [ ] useContext asoslari

**Django:**
- [ ] Django REST Framework (DRF)
- [ ] Serializer, ViewSet
- [ ] JWT autentifikatsiya (`simplejwt`)
- [ ] React frontend bilan ulash

---

### 21–30-kun: Full-stack loyiha

**Loyiha g‘oyalari:**
- [ ] Blog platformasi
- [ ] Mahsulot katalogi (CRUD)
- [ ] To‘liq auth: Login, Signup, Protected Routes
- [ ] Django API + React UI
